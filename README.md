# limeLight - Frontend Storefront & Admin Panel

Complete frontend application for **Limelight Online Clothing Brand**, built with **React**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- **Storefront**:
  - Dynamic Hero Banner Slider
  - Interactive Feature Bar
  - Dynamic Navigation Routes & Category Browsing
  - Full Product Showcase, Filters, and Detail Modals
  - Shopping Cart, Checkout Modal, and Order Placement
  - User Authentication, Profile & Real-time Order Tracking
  - AI Shopping Stylist Assistant with animated side-docking
  - Dynamic Footer with Newsletter Subscription

- **Admin Control Panel (`/admin`)**:
  - Hero Slider Management (CRUD, drag-and-drop / reorder, upload images)
  - Navigation Routes Manager (Add/Edit/Delete, Activate/Deactivate routes)
  - Header & Branding Settings (Custom text/image logo, color customizer)
  - Feature Highlights Bar CRUD
  - Footer & Newsletter Subscribers Management
  - Real-time Order Management & Customer Analytics

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Animations
- **Icons**: Lucide React
- **Routing**: React Router DOM 7

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The application will start on `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
